# Brand asset inventory

Version 2. Last audited: 2026-08-15, against the working tree at
`/home/user/n.abl`.

What exists, where it lives, how it is regenerated, and what is missing. Rules
for using any of it are in [`brand-guidelines.md`](brand-guidelines.md).

Everything listed under "exists" is committed to the repository unless stated
otherwise. `dist/` is build output, is gitignored, and is never a source of
truth.

---

## 1. Masters

The only three files any other asset is allowed to derive from.

| File | Format | Size | What it is |
|---|---|---|---|
| `public/brand/wordmark.svg` | SVG, `viewBox="0 0 273 100"` | 2 KB | The full wordmark. Drawn artwork: 13-unit monoline stroke, butt caps, true-circle curves, optical gaps 7 / 7 / 13 / 10. The construction is documented in comments inside the file. |
| `public/brand/mark.svg` | SVG, `viewBox="0 0 104 100"` | 1 KB | The short mark: geometric `n` plus the square dot. For avatars, favicons and any lockup narrower than 72 px. |
| `public/favicon.svg` | SVG, `viewBox="0 0 100 100"` | 508 B | The mark inset at 0.86 scale in a rounded espresso tile, `rx="22"`. Colours are hard-coded because a favicon has no cascade to inherit from. |

Both wordmark and mark take their letterform colour from `currentColor` and
their dot colour from `var(--mark-accent, #E9AC57)`, so a colourway is set by
the parent rather than by editing the file.

**A fourth copy of the path data exists**, inline in the `Logo` component at
`src/components/ui/index.jsx`. It is inline so the navigation does not wait on
a network request. It is a duplicate and it will drift: if a master changes,
change the component in the same commit.

## 3. Typefaces

`public/fonts/`, all self-hosted. Rationale is in
[`brand-guidelines.md`](brand-guidelines.md) section 5.3.

| File | Size | Family and subset |
|---|---|---|
| `SpaceGrotesk-latin.woff2` | 22 KB | Space Grotesk, latin. Preloaded. |
| `SpaceGrotesk-latin-ext.woff2` | 18 KB | Space Grotesk, latin-extended |
| `InterTight-latin.woff2` | 44 KB | Inter Tight, latin. Preloaded. |
| `InterTight-latin-ext.woff2` | 88 KB | Inter Tight, latin-extended |
| `JetBrainsMono-latin.woff2` | 31 KB | JetBrains Mono, latin |
| `JetBrainsMono-latin-ext.woff2` | 11 KB | JetBrains Mono, latin-extended |
| `fonts.css` | 8 KB | 16 `@font-face` blocks across three families, split by `unicode-range` |
| | **214 KB** | Total for all six font files |

Each file is a variable font, so one file serves every weight in its family and
subset. That is why several `@font-face` blocks share a `src`. Do not
consolidate them; the `unicode-range` split is what keeps the first load to
66 KB.

Caching is set in `netlify.toml`: `/fonts/*` is `max-age=31536000, immutable`.

## 5. Regeneration

None of these are wired into `package.json`, so they have to be run by hand.
That is a gap, listed in section 7.

```bash
node scripts/build-logos.mjs    # rewrites all six PNGs in logos/
node scripts/build-og.mjs       # rewrites public/brand/og.png
cd nabl-emails && ./build-eml.sh   # rebuilds the six .eml files from .html and .txt
npm run test:emails             # measures email contrast in a real browser
```

Both build scripts require Playwright's Chromium, which is already a dev
dependency.

**Order matters.** If a master changes: edit the SVG, update the inline path
data in `src/components/ui/index.jsx`, run `build-logos.mjs`, run
`build-og.mjs`, then rebuild the email pack. Committing a changed master
without the regenerated derivatives leaves the deck and the site disagreeing.

**Never hand-edit** a `.eml` file or a PNG. Both are generated.

## 7. What is missing

Priority is by consequence, not effort. P1 items are things whose absence is
visible to a client or breaks reproducibility.

### P1

| Missing | Why it matters | Depends on |
|---|---|---|
| `scripts/fetch-fonts.sh` | `fonts.css` claims it exists. Without it the font subsets cannot be regenerated, re-subsetted or updated, and the 214 KB in the repository becomes unreproducible binary. | Nothing. Write it. |
| OFL licence files for Space Grotesk, Inter Tight and JetBrains Mono | All three are SIL Open Font License 1.1, which requires the licence to travel with the font files. Self-hosting without the licence is the one way to get self-hosting wrong. | Nothing. Copy the three `OFL.txt` files into `public/fonts/`. |
| A generator for `public/brand/wordmark-email.png` | The file exists and is used in six live templates, but nothing in the repository can rebuild it. | `apple-touch-icon.png`, 180 × 180 | `index.html` declares only `<link rel="icon" href="/favicon.svg">`. iOS ignores SVG favicons for home-screen icons and substitutes a screenshot of the page. | Nothing. Render from `favicon.svg`. |
