Outlook.com / Hotmail

  1. Settings (gear icon) → Account → Signatures
  2. Name it, click in the box, press Ctrl+V (Cmd+V on Mac)
  3. Choose it as the default for new messages and replies
  4. Click Save

Gmail

  1. Settings (gear icon) → See all settings
  2. General → Signature → Create new
  3. Paste into the box and set it as the default
  4. Scroll down and click Save Changes

Do this on a computer. The Outlook and Gmail phone apps only take plain-text signatures.
