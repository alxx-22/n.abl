How to record

Quickest — no keying. Use my webcam, then Guides off, then Clean view, then screen-record the stage. It is already composited. Good enough to post.

Proper — true 1080×1920, in OBS. No screen recording, no scaling loss:

  1. Add a Browser source. Tick Local file, pick this file, set width 1080 and height 1920.
  2. Put ?clean=1&guides=0&cam=key&play=1 on the end of the URL. It opens with no panel, no guides, at exactly 1:1, playing.
  3. Add your Video Capture Device and drag it below the browser source in the list. The reel sits on top; your face shows through the window it cuts.
  4. On the browser source: Filters → Chroma Key → Green.
  5. Set the canvas to 1080×1920 at 60fps and record. Tick Refresh browser when scene becomes active and every take starts from the top.

Two sections put type over a full-frame camera. Keying those fringes the letters green, so either use the webcam mode, or record a second pass with Text off and lay the type back over the top.
